# DLinear + AIA193 + Ridge: выбранный подход

Единственная активная схема: фиксированный DLinear, признаки AIA193 каждые
6 часов, фиксированное временное окно и Ridge-поправка по шести диапазонам
горизонта. CNN, LightGBM и другие варианты убраны из активного кода.
Runtime-интеграция добавлена в forecast/Clio/Prophet; реестр указывает на новый артефакт.
На сервере требуется применить миграцию Clio и развернуть обновлённые сервисы.

Для t+h центр окна — t+h−96h, ограниченный последним доступным наблюдением.
Ширина ±24h, Gaussian sigma12h. На96–120h только последний доступный снимок.
Признаки: площади тёмных областей в15 секторах, изменения за24h и солнечный
оборот, геометрия, возраст, календарь и прогноз DLinear. Произвольных вращений
изображений нет. Данные FITS сохранены в исходном размере.

Обучение поправки2023–2024, валидация Q2/Q3/Q4 2024, исторический тест2025.
Ridge alpha100; масштабы поправки по диапазонам1–6/7–24/25–48/49–72/73–96/97–120:
**0 / 0 / 0 / 0.25 / 0.25 / 0.5**. DLinear ранее обучен на1995–1999 и заморожен.
Параметры записаны в `plan.json`; пропущенные цели не заполняются.

| Модель | MAE1–120h | MAE ровно t+96 | RMSE ровно t+96 |
|---|---:|---:|---:|
| DLinear | 67.76 | 76.19 | 103.59 |
| DLinear + AIA193 + Ridge | **66.93** | **75.80** | 103.95 |

Ошибки в км/с. Общие цели:172820 пар на1–120h,1435 наt+96.
2025 многократно исследован — это не независимая оценка. Задержка публикации
AIA2h условная; тёмные области не равнозначны подтверждённым корональным дырам.
Числа56.85/77.01 из старого Q2 2026 относятся к другому протоколу.

## Запуск

Из корня репозитория:

```bash
# Проверка сохранённой модели и входов, без обучения/загрузки.
.venv/bin/python scripts/training/aia_wind/run_experiment.py verify
# Воспроизвести метрики сохранённого выбранного варианта.
.venv/bin/python scripts/training/aia_wind/run_experiment.py evaluate
# Только если нужно пересоздать входы и переобучить тот же подход:
.venv/bin/python scripts/training/aia_wind/run_experiment.py features
.venv/bin/python scripts/training/aia_wind/run_experiment.py prepare
.venv/bin/python scripts/training/aia_wind/run_experiment.py fit
.venv/bin/python scripts/training/aia_wind/run_experiment.py evaluate
```

`features` использует локальный архив, сеть не нужна. После изменения входов
нужно явно выполнить `fit`: проверка не принимает устаревшую модель молча.
Notebook: `notebooks/4_aia_wind_residual.ipynb`, по умолчанию только чтение.

## Файлы

- `run_experiment.py`: подготовка выборки, временная валидация, обучение и оценка.
- `alignment.py`: причинное фиксированное окно AIA.
- `aia_features.py`: извлечение признаков и регистрация изображений.
- `backtest.py`: наблюдаемые цели OMNI и набор признаков.
- `stream_ridge.py`: стандартизованный Ridge и импутация.
- `fetch_aia.py`: возобновляемая загрузка при явном запуске.
- `utils.py`, `plan.json`: хеши/настройки.

Данные: `data/experiments/aia_wind/selected_fixed_window_ridge_v1/`.
Модель и результаты: `data/metrics/aia_wind/selected_fixed_window_ridge_v1/`.
Нужны также неизменённые AIA193 FITS, OMNI, замороженный DLinear и его OOF
в общих каталогах. Исходные AIA193/AIA211/GONG и другие задачи не удалялись.

История закрытых опытов: `data/reports/retired_experiments/aia_research_20260923.zip`.
В архиве только исходники, планы, тесты, компактные отчёты/таблицы и SHA256;
устаревшие модели, прогнозы и нейросетевые массивы удалены. Исходные пути
в архиве исторические. Перенос выбранной схемы проверен точным совпадением
признаков2023–2025, повторного обучения и прогнозов2025.
Журнал очистки: `docs/research/aia_cleanup_20260923.md`.


## Экспорт для сервиса

`.venv/bin/python scripts/training/aia_wind/export_model.py export` сохраняет единый артефакт
скорости/порогов в `data/models/argus-plasma-speed-aia-ridge-v1.joblib` и проверяет
точное совпадение точечного прогноза. Неопределённость — ошибки временной валидации
2024 отдельно для каждого горизонта, центрированные для сохранения q50.
Метрики и ограничения: `data/metrics/plasma/`. Для применения на сервере
нужны обновлённые сервисы, артефакт и миграция `20260923_aia_snapshot`.

## Расположение и проверка

Это поддерживаемый конвейер обучения, оценки и экспорта рабочей модели.
`run_experiment.py` сохраняет имя для проверки хешей замороженного протокола.
Исторические пути входных данных `data/experiments/...` также сохранены: они записаны в протоколе и не означают наличие экспериментального runtime-кода.

Оценить текущий сервисный артефакт без переобучения:

```bash
.venv/bin/python scripts/training/aia_wind/export_model.py evaluate
```

Сводка метрик: `data/metrics/plasma/README.md`.
